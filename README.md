# ポートフォリオサイト

クラウドワークスのプロフィールに載せるためのポートフォリオです。Next.js で作り、静的ファイルとして書き出します。

## 動かす

```bash
npm install
npm run dev      # http://localhost:3000
```

## 内容を書き換える

文章はすべて `src/data/` にまとめてあります。画面のコードを触らずに更新できます。

| ファイル | 内容 |
| --- | --- |
| `src/data/profile.ts` | 名前、キャッチコピー、強み、経歴、スキル、受けられる仕事、クラウドワークスのURL |
| `src/data/works.ts` | 制作実績。1件ずつ、概要・技術・機能・工夫した点を書く |
| `public/works/` | 制作実績のスクリーンショット（1440×900） |

`profile.ts` の `crowdworksUrl` にプロフィールのURLを入れると、「クラウドワークスで相談する」ボタンが出ます。

作品を追加するときは `works.ts` の配列に1件足し、画像を `public/works/` に置いて `image.src` で指定します。画面を見せられない作品は `image` を書かなければ、タイトル入りの表示になります。

## 公開する

```bash
npm run build    # out/ に静的ファイルが出力される
```

- **Vercel**：GitHub のリポジトリを読み込めば、設定なしで公開されます
- **レンタルサーバー**：`out/` の中身を公開ディレクトリにアップロードします
